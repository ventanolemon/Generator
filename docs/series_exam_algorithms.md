# Алгоритмы генерации контрольной по рядам (вариант №0 → генератор)

Прототип — контрольная работа из 8 заданий (числовые ряды → функциональные →
степенные → Тейлор). Здесь зафиксированы алгоритмы генерации «аналогичных»
заданий: те же темы и уровень, но случайные параметры И случайная развилка
паттерна решения, где это уместно. Реализация — графы в
`exercises/graph_examples/series_exam.py` (по одному графу на задание),
`generate_variant(seed)` собирает целый вариант.

Общий принцип всех восьми генераторов: **ответ не «решается» тяжёлой CAS, а
вычисляется из структуры параметров** (показатели p-рядов, предел Даламбера,
радиус как min расстояний до полюсов). Это то же обращение задачи, что и в
рукописных генераторах: сначала выбирается «удобная» структура ответа, затем
из неё собирается условие. sympy используется для точной печати (дроби,
знак суммы, apart), а не для решения.

---

## 1. Сходимость знакоположительного ряда (сравнение с p-рядом)

Условие: `Σ ((a·n^d1 + e)/(b·n^d2 + f))^p · arctg(1/√n)`.

| параметр | диапазон | роль |
|---|---|---|
| a, b | 2..7 | коэффициенты дроби |
| e, f | 1..3 | «шум» младших членов |
| p | 2..5 | внешняя степень |
| ветка d | 0/1 | **паттерн решения** |

Ветка d=1: d1=2, d2=3 (разность степеней 1) → aₙ ~ C·n^(−p)·n^(−1/2),
s = p + 1/2 > 1 — **сходится**. Ветка d=0: d1=d2=1 → дробь → C ≠ 0,
aₙ ~ C·n^(−1/2), s = 1/2 — **расходится**. Ответ: вердикт + показатель s.
Развилка структуры условия реализована `select(value_type=expr)` между двумя
`expr_const`.

Оси разнообразия дальше (после банка заданий): медленный множитель из пула
{arctg(1/√n), sin(1/n), ln(1+1/n), 1−cos(1/n)} с соответствующим α.

## 2. Признак Даламбера (факториалы и показательные)

Условие: `Σ a^(b·n) · (n!)^c / (c·n)!`, c ∈ {2,3}, a ∈ 2..9, b ∈ {1,2}.

Предел отношения известен в замкнутой форме: L = a^b / c^c (при равенстве
степени факториала и кратности). Guard отбрасывает вырожденный случай L = 1.
Вердикт: L < 1 → сходится, L > 1 → расходится; в ответе точная дробь L
(например 25/27) — `expr_const "a**b/c**c"` даёт `sympy.Rational`.

## 3. Абсолютная/условная сходимость знакочередующегося ряда

Условие: `Σ (−1)^(n+1) · n^p / (n^q + c)`, p ∈ 1..3, c ∈ 1..6.

**Категория ответа k разыгрывается первой** (0..2), а q подбирается под неё:
q = p + 2 − k. Тогда s = q − p:

* k=0 → s=2: сходится **абсолютно** (|aₙ| ~ n^(−2));
* k=1 → s=1: сходится **условно** (Лейбниц; ряд модулей ~ гармонический);
* k=2 → s=0: aₙ ↛ 0 — **расходится**.

Три текста ответа выбираются цепочкой `select(block)`.

## 4. Радиус/интервал сходимости степенного ряда + равномерная сходимость

Условие: `Σ (−1)^n (x − x0)^n / ((a·n + b) · R^n)`, R ∈ 1..3, x0 ∈ 0..3,
a ∈ 1..4, b ∈ 1..3.

Радиус заложен конструктивно: |c_n/c_{n+1}| → R. Концы известны по построению:
x = x0+R → Σ(−1)^n/(an+b) — условная сходимость (Лейбниц);
x = x0−R → Σ1/(an+b) — расходится (сравнение с гармоническим).
Область равномерной сходимости: [c; x0+R] для любого c > x0−R (Абель).
Ответ — шаблон с числами lo = x0−R, hi = x0+R.

## 5. Признак Вейерштрасса (равномерная сходимость на ℝ)

Условие: `Σ n^p · x / (1 + c · n^q · x²)`, −∞ < x < +∞.

Конструкция гарантирует применимость признака: p ∈ 1..2, запас m ∈ 1..3,
q = 2p + 2 + m, c = k² (k ∈ 2..5 — чтобы √c был целым). Мажоранта по AM–GM:
1 + c n^q x² ≥ 2k n^(q/2) |x| ⇒ |uₙ| ≤ n^(p−q/2)/(2k) = Mₙ,
s = q/2 − p = 1 + m/2 > 1 ⇒ Σ Mₙ сходится. Ответ содержит Mₙ и s.

## 6. Неравномерная сходимость на интервале

Условие: `Σ (x − x0)^(k·n)`, x0 − 1 < x < x0 + 1; x0 ∈ 0..2, k ∈ {2,4}.

Геометрический ряд по t = (x−x0)^k ∈ [0;1): сумма S = t/(1−t), остаток
rₙ = t^(n+1)/(1−t) не мал равномерно (sup по x бесконечен у концов). Ответ:
замена, S(x) точным выражением, аргумент про sup остатка.

## 7. Рациональная дробь → степенной ряд + f^(m)(x)

**Обратное конструирование:** выбираются простейшие дроби A/(x+p) + B/(x+q)
(A,B ∈ 1..4; p ≠ q ∈ 1..5 — guard), затем f(x) = ((A+B)x + (Aq+Bp)) /
((x+p)(x+q)) — разложение заведомо «красивое». x0 ∈ 0..3, m ∈ {50,100,200}
(чётные — знак производной «+»).

Ответ: 1) apart(f) — узел `apart` печатает разложение; 2) общий член ряда
Σ (−1)^n (A/(x0+p)^{n+1} + B/(x0+q)^{n+1}) (x−x0)^n; 3) область
|x−x0| < R, R = min(x0+p, x0+q) — `select` по `compare`; 4) f^(m)(x) =
m!·(A/(x+p)^{m+1} + B/(x+q)^{m+1}).

## 8. Ряд Тейлора ln(x+a) + почленное дифференцирование

a ∈ 2..9. Ответ в замкнутой форме через `Eq(...)` + `Sum(...)` одним
`expr_const`: ln(x+a) = ln a + Σ (−1)^(k+1) x^k/(k a^k), k=1..∞;
производная: 1/(x+a) = Σ (−1)^k x^k/a^(k+1), k=0..∞.
Область: −a < x ≤ a; после дифференцирования |x| < a.

## Управление сложностью и оригинальностью

* **Числа** — из узких «педагогических» диапазонов (2..9), guard отсекает
  вырожденности (L=1, p=q).
* **Паттерн решения** — отдельная случайная величина (ветка в №1, категория
  в №3), а не следствие чисел: в варианте гарантированно встречаются разные
  исходы, контрольная не «выцветает» в один шаблон.
* **Воспроизводимость** — meta.seed; `generate_variant(seed)` даёт вариант
  из 8 согласованных заданий (seed·100+i).
* После присланного банка заданий пулы структур расширяются точечно: новые
  медленные множители в №1, семейства (n!)²/(2n)! и n!/nⁿ в №2, центры x0 ≠ 0
  и чётные степени (x−x0)^{2n} в №4 и т.д. — каждая ось это items у
  `random_choice` или новая ветка `select/case`, без изменения движка.

## Анализ банка заданий (методичка, задачи 2.2–2.6)

Присланный банк подтвердил гипотезу «структурных семейств» и дал конкретные
пулы; расширения выполнены точечно, движок менять не пришлось (кроме трёх
эргономических правок, описанных ниже).

* **Задача 2.2** (28 вариантов степенных рядов) → №4 расширен до **четырёх
  семейств коэффициентов** с разным поведением концов: (а) правый конец
  условно/левый расходится, (б) зеркально, (в) оба абсолютно (~1/n²),
  (г) оба расходятся (aₙ ↛ 0). Семейство выбирает и структуру условия
  (`pick expr`), и текст ответа (`pick block`).
* **Задача 2.4** (28 вариантов Вейерштрасса) → №5 расширен до **трёх
  структурных типов**: AM–GM на всей оси; ограниченный тригонометрический
  числитель |sin(anx)| ≤ 1 (Mₙ = n^−(p+1/2)); степень xⁿ/kⁿ на отрезке
  [−k; k] (Mₙ = 1/(n²+w)). Промежуток в условии тоже выбирается pick-ом.
* **Задача 2.5** (28 разложений Тейлора) → новый генератор №9:
  y = A·(x−x₀)^j·F(k(x−x₀)), F ∈ {exp, sin, cos, sh, ch} — пять табличных
  разложений; ответ — готовое тождество Eq(…, Sum(…)); x₀ ∈ −3..3.
  Семейства с ln/арктангенсом/дробями остаются осью расширения (у них
  конечная область сходимости — нужен отдельный текст ответа).
* **Задача 2.6** (f⁽ⁿ⁾ через ряды) — покрыта паттерном №7 (обратное
  конструирование от простейших дробей); банковские варианты с e^g(x) и
  sin² — кандидаты в пул №7/№9.
* **Задача 2.3*** (область сходимости функционального ряда) — не реализована:
  необязательная по методичке; требует решения неравенств |g(x)| < 1
  (sympy solveset по рациональным g) — отдельный узел-решатель неравенств,
  осознанно отложено.

## Правки языка по итогам банка

1. **`pick`** — N-канальный мультиплексор по индексу (замена цепочек select
   при 3+ вариантах): именно он сделал семейства дешёвыми (2 узла на выбор
   структуры и ответа вместо 2(N−1) select-ов).
2. **`formula` constants='off'** — буквы c/e/g/… становятся переменными
   («чистая математика»), pi остаётся константой; footgun скорости света
   закрыт по-настоящему, а не только документацией.
3. **Динамический `prefix`** — вход prefix:STRING у expr_block/matrix_block/
   to_block (значение из графа перекрывает статический параметр).
