# Алгоритмы генерации контрольной по ТФКП (комплексный анализ)

Прототип — банк методички: №1 формы комплексного числа, №2 области на
плоскости, №3 все значения многозначной степени, №4 трансцендентные
уравнения. Реализация — `exercises/graph_examples/complex_exam.py`;
`generate_complex_variant(seed)` собирает вариант. Ключевая новизна —
**графика**: области и точки рисуются узлами plot-категории прямо в ответ.

## №1. Формы комплексного числа

Пул «красивых» множителей a+bi с табличными |w| и arg w (π/6, π/4, π/3…);
z = (w₁·w₂)^N или (w₁/w₂)^N, N ∈ 3..9. Алгебраическая форма — точным
expand_complex→simplify→expand; r = |z| упрощением; **аргумент — структурно**:
φ = Mod(N(φ₁ ± φ₂) + π, 2π) − π (sympy не сворачивает «смешанные» углы вроде
7π/12, а сумма табличных — точная рациональная кратная π). Условие
отображается неупрощённым через шаблон UnevaluatedExpr + subs_expr — в пуле
только суммы a+bi (одиночные 2i печатались бы без скобок). Тождество
r·e^{iφ} = alg проверяется в тестах численно по сидам.

## №2. Область на комплексной плоскости

4 семейства (pick выбирает условия, текст условия и текст ответа):
кольцо r₁<|z−A|<r₂; круг |z+Ai|<r при Re z<0; открытый прямоугольник
0<Re z<a, −b<Im z<0; сектор |z|<r, 0<arg z<π/k. Условия — строки от z
(«abs(z-2)<3») из template-узлов, собранные list_new → complex_region_plot
штрихует пересечение на numpy-сетке. Ответ: словесное описание + картинка.

## №3. Все значения многозначной степени

Два семейства: m^i (значения e^{−2πk}·(cos ln m + i·sin ln m) — луч
arg w = ln m) и (−m)^{√p} (значения m^{√p}·e^{i√p·π(2k+1)} — окружность
радиуса m^{√p}). Точки ветвей k строятся ЦИКЛОМ: общий член с символом K
уходит в тело через expr-туннель, expr_subs подставляет K = i − off,
список точек возвращается туннелем-списком → complex_points_plot.

## №4. Трансцендентные уравнения

Три семейства: e^z = w (пул красивых правых частей; z = ln r + i(φ+2πk));
cos z = a, a>1 (z = 2πk ± i·ln(a+√(a²−1))); sh z = b (z = arsh b + 2πik и
z = −arsh b + iπ(2k+1)). Обе ветви — ОДНИМ циклом: K = floor(i/step) − 1,
S = ±1 чередуется внутри пары; терм-шаблон с K, S подставляется expr_subs.
Точные константы (ln(2+√5), π/2) входят в шаблон через subs_expr. Корни
k = −1..1 рисуются complex_points_plot («решётка корней»); в тестах каждая
точка подставляется в уравнение численно (|cos z − a| < 1e−6).

## Правки языка под ТФКП

1. **Категория plot**: `complex_points_plot` (LIST → IMAGE; sympy/complex/
   пары; авто-масштаб, подписи координат, опц. единичная окружность) и
   `complex_region_plot` (LIST строк-условий → IMAGE; AST-whitelist
   безопасной оценки: только арифметика/сравнения/вызовы abs/re/im/arg…).
   matplotlib — ленивый импорт (движок остаётся headless).
2. **subs_expr** — подстановка ВЫРАЖЕНИЯ вместо символа (expr_subs умел
   только числа): шаблонные ответы с точными r, φ, ln(2+√5).
3. **list_concat** (LIST+LIST) — ветви корней в один список.
4. **as_expr интифицирует целые float** — z^4.0 из NUMBER-провода ломал
   точное раскрытие (общий фикс коэрции NUMBER→EXPR).
5. **_marker_str**: π, i, ln, √ в текстовых ответах.
6. Задокументированный инвариант: многобуквенные символы шаблонов обязаны
   быть объявлены в vars — иначе имплицитное умножение расщепит R0 → R·0.

## №5. Гармоническая функция — восстановить f(z) (банк «Задача 6б»)

Обратное конструирование: f₀(z) из пула {sin, cos, exp, sh, ch, z²} — её
Re/Im ровно табличные гармонические части (sin(kx)ch(ky), e^{kx}cos(ky), …).
Дана одна часть (Re или Im, разыгрывается) + f(z₀); z₀ = 0 (f₀(0) ∈ {0,1} —
условие чистое). Ответ: f(z) = f₀(z) + iC (если дана Re) или + C (если Im),
константа из f(0) = W. Гармоничность — лапласиан Δh = h_xx + h_yy = 0
(узлы diff с var=x/y, order=2). Проверка: f(0) = W и Δ = 0 численно.

## №7. Отображение области ω = a·zⁿ + b (банк «Задача 7»)

D₁ = {|z| ≤ R, α₁ ≤ arg z ≤ α₂} — сектор круга; ω = a·zⁿ + b. Под zⁿ радиус
Rⁿ, углы ×n; ×a — масштаб |a|, поворот arg a; +b — сдвиг центра. Итог: D₂ =
{|w − b| ≤ |a|Rⁿ, nα₁+arg a ≤ arg(w−b) ≤ nα₂+arg a}. Условия D₁ и строка
отображения строятся шаблонами; узел `conformal_map_plot` рисует D₁ (заливка
маски) и D₂ (ПРЯМОЙ образ сетки — обходит разрез arg) двумя панелями. Те же
строки `parse_expr` разбирает в EXPR для точного описания D₂ в ответе
(радиус |a|Rⁿ, углы β = nα+arg a).

## Правки языка (второй заход по ТФКП)

1. **`conformal_map_plot`** (plot) — область D₁ + её конформный образ
   D₂ = f(D₁), две панели; безопасный AST-eval и для условий, и для
   отображения (общий `_safe_z_eval`); π добавлен в неймспейс.
2. **`parse_expr`** (symbolic) — STRING → EXPR в рантайме: строку-вариант,
   выбранную random_choice, можно и подставить в текст/условие как есть, И
   разобрать в выражение для математики ответа. Закрыл дыру «нет обратной
   операции к печати выражения строкой».
3. **`expr_subs` интифицирует значения** (`_num`): целые float из
   NUMBER-провода (0.0, 2.0) → точные Integer, иначе ответы «плыли»
   (f(0) = −1.0, углы 1.5·π вместо 3π/2).
4. **`_marker_str`**: убирает '*' перед π/i/√ ('3*i' → '3i', '2*π' → '2π').
